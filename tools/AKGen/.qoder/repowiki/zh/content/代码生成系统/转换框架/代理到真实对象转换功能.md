## 简介

本文档详细介绍了基于 ArkTS 与 Kotlin FFI（Foreign Function Interface）的代理到真实对象转换功能。该功能允许在 ArkTS 层创建 Kotlin 类的代理对象，并提供双向转换机制，使得 ArkTS 对象可以与 Kotlin 对象进行互操作。

**更新** 该系统现已支持 Kotlin Multiplatform 兼容性，能够生成 expect 类声明与 actual 实现类，为多平台项目提供完整的类型安全转换支持。新增的条件性期望类生成功能可以根据配置和类要求智能地决定是否生成期望类，提高了系统的灵活性和适用性。

**更新** 新增的序列化名称映射支持和配置导入功能进一步增强了系统的实用性。系统现在能够处理 Kotlin 的 SerializedName 注解，并通过 enable_json_name 配置项控制 JSON 名称映射功能。

**更新** 最重要的改进是修复了映射函数构建逻辑中的关键bug：修正了非代理类型处理中的提前返回问题，确保所有类类型的映射函数都能正确构建。这一修复解决了之前可能导致某些类类型无法生成完整转换函数的问题，大大增强了系统的稳定性和可靠性。

该系统的核心特性包括：
- 自动代理类生成：为每个 Kotlin 类生成对应的 ArkTS 代理类
- 类型安全转换：确保 ArkTS 和 Kotlin 对象之间的类型兼容性
- 字段映射机制：支持通过装饰器配置字段的名称和类型映射
- 共享标识符支持：通过 ID 机制实现跨语言的对象关联
- 自动转换器生成：为自定义对象类型生成专用的转换器
- **新增**：增强的 expect/actual 类生成逻辑，包括 convert_prop_decl() 函数
- **新增**：改进的 convert_class() 函数，支持条件性期望类生成
- **新增**：智能的 needs_expect_class 变量逻辑，控制期望类生成
- **新增**：基于 share_type 配置的智能期望类生成机制
- **新增**：序列化名称映射支持（SerializedName 注解）
- **新增**：配置导入支持（enable_json_name 配置项）
- **新增**：改进的类名包名处理逻辑
- **新增**：修复的映射函数构建逻辑，确保所有类类型都能正确处理

#### 字段映射规则

字段映射遵循以下优先级规则：

1. **装饰器 ID 匹配**：使用 `@ExportField.id` 和 `@ExportClass.id` 进行精确匹配

3. **类型匹配**：确保 ArkTS 和 Kotlin 字段类型兼容
4. **可变性检查**：只转换可变字段，跳过只读字段

## 故障排除指南

### 常见错误及解决方案

#### 1. 类名冲突错误

**错误信息**：`[Error 1003] Duplicate class name 'XXX' found in package 'YYY'`

**原因**：同包名下的类名重复

**解决方案**：
- 检查装饰器中的 `name` 参数
- 确保类名在指定包内唯一
- 使用 `@ExportClass` 的 `id` 参数进行区分

#### 2. 字段 ID 重复错误

**错误信息**：`[Error 2003] Duplicate field_id 'XXX' found in class 'YYY'`

**原因**：同一类内的字段 ID 重复

**解决方案**：
- 检查 `@ExportField.id` 的唯一性
- 为每个字段分配唯一的 ID

#### 3. 共享 ID 未找到错误

**警告信息**：`ShareId XXX not found`

**原因**：ArkTS 中指定的共享 ID 在 Kotlin 中找不到对应类

**解决方案**：
- 确保 Kotlin 类使用了正确的 `@ShareClass` ID
- 检查 ID 的拼写和大小写

#### 4. 类型不匹配错误

**更新** 改进的警告消息现在更清晰地指明问题所在：

**警告信息**：`Generate to/from real func: Proxy field ProxyClass.fieldName and Kotlin field RealClass.fieldName type mismatch`

**原因**：ArkTS 和 Kotlin 字段类型不兼容

**解决方案**：
- 检查装饰器中的 `type` 参数
- 确保类型转换规则适用
- 必要时手动指定类型

#### 5. 字段不可变错误

**更新** 新增的警告消息区分不同类型的字段问题：

**警告信息**：`Generate to/from real func: ArkTS field ProxyClass.fieldName is not mutable.`

**原因**：ArkTS 字段为只读属性

**解决方案**：
- 将 ArkTS 字段标记为可变（var）
- 或者移除该字段的转换需求

#### 6. 类名解析失败错误

**更新** 新增的类名解析系统错误处理：

**错误信息**：`[Error 1004] Duplicate id 'XXX' found in class 'YYY'. Each class must have a unique id.`

**原因**：装饰器 ID 重复

**解决方案**：
- 确保每个类的 ID 在整个项目中唯一
- 检查 `enableShareId` 配置是否正确

#### 7. 字段映射失败错误

**更新** 新增的字段映射错误处理：

**警告信息**：`Generate to/from real func: Proxy field ProxyClass.fieldName: type has no corresponding member in RealClass`

**原因**：找不到对应的 Kotlin 字段

**解决方案**：
- 检查字段名称和类型映射
- 确保 Kotlin 类中有对应的字段
- 验证装饰器配置的正确性

#### 8. 条件性期望类生成错误

**更新** 新增的条件性期望类相关错误处理：

**错误信息**：`Condition check failed for expect class generation`

**原因**：条件性期望类生成的条件判断失败

**解决方案**：
- 检查 `share_type` 配置是否为 'proxy'
